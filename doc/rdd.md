# 登園連絡アプリ要件定義書

## プロジェクト概要

保育園と保護者が連携し、登園・欠席・遅刻の連絡を円滑に行うためのアプリケーション。
保護者はスマートフォンから簡単に連絡ができ、園側は一覧で確認・管理できる。

## ユーザー分析

### 保育園側

- **管理者**: 園の運営を行う。施設情報やクラスの管理、保護者との連絡を担当。
- **スタッフ**: 子どもの登園状況を記録し、保護者とのコミュニケーションを行う。

### 保護者側

- **保護者**: 子どもの登園・欠席・遅刻の連絡を行う。スマートフォンから簡単に操作可能。

## 機能要件リスト

| 機能名               | 説明                                     | 優先度 |
| ------------------ | ---------------------------------------- | ------ |
| 登園連絡作成         | 保護者が子どもの登園・欠席・遅刻を記録する           | 高     |
| 登園連絡一覧表示     | 園側が保護者からの連絡を一覧で確認する               | 高     |
| 登園連絡編集         | 保護者が送信した登園連絡を編集する                   | 中     |
| 登園連絡削除         | 保護者が送信した登園連絡を削除する                   | 中     |
| クラス管理           | 園側がクラス情報を管理する                       | 中     |
| 施設情報管理         | 園側が施設情報を管理する                       | 中     |
| 保護者との連絡       | 園側が保護者と連絡を取るための機能                   | 中     |
| ログ記録             | スタッフが子どもの登園状況を記録する               | 中     |

| 要件名         | 説明                              | 重要度 |
| -------- | ---------------------------------------- |------ |
| パフォーマンス | アプリは1000人の同時アクセスに耐えられること。           | 高     |
| セキュリティ   | ユーザーデータは暗号化され、適切な認証が必要。           | 高     |
| 可用性       | システムは99.9%の稼働率を維持すること。               | 高     |
| スケーラビリティ | 将来的なユーザー増加に対応できる設計。               | 中     |

#### 保護者の制限事項

- 自分が登録した子どもと、その子の投稿しか操作できない。
- 他人の子どもの情報や投稿は一切アクセス不可。

#### スタッフの制限事項

- 自身の所属する「クラス」に紐づく子どもや投稿のみ閲覧・操作可能。
- ログとイベントは記録できるが、投稿自体は編集できない。

#### 管理者の権限

- 園全体のすべての情報にアクセス可能。
- スタッフや施設の管理を行う。
- ソフトデリートされたデータの復元も可能。
- 管理者アカウントはDBで初期登録。

## 用語集

| 用語         | 定義                                     |
| ----------- | ---------------------------------------- |
| 登園連絡       | 保護者が子どもの登園・欠席・遅刻を記録するための連絡。         |
| クラス         | 保育園内での子どものグループ。クラスごとに担当スタッフがいる。     |

## 開発環境構築ガイド

1. **Node.jsのインストール**
   - Node.jsを公式サイトからダウンロードし、インストールします。
   - バージョンはLTS（Long Term Support）を推奨。
2. **Next.jsプロジェクトの作成**
   - ターミナルを開き、以下のコマンドを実行します。

     ```bash
     npx create-next-app@latest my-app --typescript

   ```markdown

   - `my-app`はプロジェクト名です。任意の名前に変更可能。

3. **Firebaseのセットアップ**

   - Firebaseコンソールで新しいプロジェクトを作成します。
   - Firestoreデータベースを有効化し、必要なコレクションを作成します。
   - Firebase Authenticationを設定し、メールアドレスとパスワード認証を有効にします。
4. **Firebase SDKのインストール**
   - プロジェクトディレクトリに移動し、以下のコマンドを実行します。

     ```bash
     npm install firebase
     ```

   ```markdown

5. **環境変数の設定**

   - プロジェクトルートに`.env.local`ファイルを作成し、Firebaseの設定情報を追加します。

```NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

6. **TypeScriptの設定**

- `tsconfig.json`ファイルが自動生成されます。必要に応じて設定を変更します。
- 型定義ファイルを追加する場合は、以下のコマンドを実行します。

     ```bash
     npm install --save-dev @types/react @types/node
     ```

7. **開発サーバーの起動**

- 以下のコマンドを実行して開発サーバーを起動します。

     ```bash
     npm run dev
     ```

- ブラウザで `http://localhost:3000` にアクセスし、アプリが正しく動作することを確認します。
